# Amphora Labs

We build infrastructure for running private AI workloads.

## Featured project

[Amphora](https://github.com/amphoralabs/amphora) is our flagship project: an open-core Kubernetes
operator and serving platform for private LLM fleets, focused on GPU utilization, fast model
startup, and cost visibility.

Amphora is in early development. Visit its repository for the latest status, roadmap, and
contribution guidance.
